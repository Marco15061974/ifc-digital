IFC Digital Developer Preview 0.1

Dieses Paket ist veröffentlichungsfertig.

Option A – Netlify:
1. netlify.com öffnen und anmelden.
2. Den entpackten Ordner in 'Deploy manually' ziehen.
3. Den erzeugten Link auf dem Galaxy Tab öffnen.
4. In Chrome: Menü > Zum Startbildschirm hinzufügen.

Option B – GitHub Pages:
1. Dateien in ein neues Repository hochladen.
2. Settings > Pages > Deploy from branch.
3. Den veröffentlichten Link öffnen.

Wichtig:
Die PWA-Installation funktioniert erst zuverlässig über HTTPS, also nach dem Hosting.
